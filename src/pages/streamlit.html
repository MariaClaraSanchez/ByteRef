Streamlit

apps de dados em Python

Resumo

Streamlit transforma um script Python em app web interativo, sem HTML nem JavaScript. Cada widget (slider, filtro, upload) dispara um rerun: o script roda de novo de cima a baixo com os novos valores.

  • Para que serve: publicar análises feitas com Pandas como dashboards, protótipos de ferramentas internas e demos de modelos e LLMs.
  • Quando usar: ferramentas internas e painéis de dados em que velocidade de entrega importa mais que controle fino de layout.
  • Quando evitar: produtos com muitos usuários simultâneos, regras complexas de autenticação ou interface sob medida; nesses casos, uma API (Flask) com um front-end próprio é melhor.

Conceitos-chave

Script e rerun

O app é um script comum. A cada interação, o Streamlit executa o arquivo inteiro de novo e redesenha a página.

Widget

Componente de entrada (st.slider, st.selectbox, st.button) que devolve o valor atual direto numa variável Python.

Cache

@st.cache_data guarda resultados serializáveis (DataFrames, JSON); @st.cache_resource guarda recursos compartilhados, como conexões e modelos.

Session state

st.session_state guarda valores por usuário entre reruns, como contadores, carrinho e etapas de formulário.

Layout

st.sidebar, st.columns, st.tabs e st.expander organizam a página sem CSS.

Secrets

Credenciais em .streamlit/secrets.toml (fora do Git) ou no painel de deploy, lidas com st.secrets.

📊 App & widgets

Python · app mínimo
import pandas as pd
import streamlit as st

st.title("Vendas por região")

df = pd.DataFrame({
    "regiao": ["Sul", "Sudeste", "Norte"],
    "valor": [120, 340, 80],
})

st.dataframe(df)
st.bar_chart(df, x="regiao", y="valor")
Python · widgets e filtro
regioes = st.multiselect("Regiões", df["regiao"].unique(), default=list(df["regiao"].unique()))
minimo = st.slider("Valor mínimo", 0, 500, 100)

filtrado = df[df["regiao"].isin(regioes) & (df["valor"] >= minimo)]
st.metric("Total", f"R$ {filtrado['valor'].sum():,.0f}")
st.dataframe(filtrado)

⚡ Cache, estado & segredos

Python · cache de dados e de recursos
import pandas as pd
import sqlalchemy
import streamlit as st

@st.cache_data(ttl=600)  # dados: recalcula no máximo a cada 10 min
def carregar_vendas(caminho: str) -> pd.DataFrame:
    return pd.read_csv(caminho)

@st.cache_resource  # recursos compartilhados: conexões, modelos
def banco():
    return sqlalchemy.create_engine(st.secrets["DB_URL"])

df = carregar_vendas("vendas.csv")
Python · session state
if "cliques" not in st.session_state:
    st.session_state.cliques = 0

if st.button("Clique"):
    st.session_state.cliques += 1

st.write("Cliques:", st.session_state.cliques)

Armadilhas & Fixes

ErroCausaCorreção
App lento a cada cliqueSem cache, cada rerun relê o CSV, refaz a consulta ao banco e recalcula tudo.Use @st.cache_data na carga e nas transformações e @st.cache_resource nas conexões.
Valor volta ao inicial a cada interaçãoVariáveis Python comuns são recriadas a cada rerun.Guarde o valor em st.session_state e inicialize só se a chave não existir.
Dados velhos ou erro ao cachearcache_data sem ttl nunca expira, e ele exige retorno serializável (conexões não servem).Defina ttl, limpe com st.cache_data.clear() e use cache_resource para conexões e modelos.
Erro de widget ou elemento duplicadoDois widgets com o mesmo tipo, rótulo e parâmetros geram o mesmo ID interno.Passe um key= único para cada widget.
Senha do banco no GitHubO .streamlit/secrets.toml foi commitado junto com o código.Revogue a credencial, adicione o arquivo ao .gitignore e configure os segredos no painel do deploy.
