Poetry

gerenciamento de dependências Python

pythonpackagingdependencies40 comandos

Resumo

Poetry gerencia dependências, ambientes virtuais e empacotamento de projetos Python a partir de um único arquivo, o pyproject.toml.

  • Para que serve: declarar dependências, resolver versões compatíveis, travar tudo num lock file e fazer build e publish de pacotes.
  • Quando usar: aplicações e bibliotecas Python em equipe, em que todos (e o CI) precisam instalar exatamente as mesmas versões.
  • Quando evitar: scripts avulsos sem dependências, ou projetos que já padronizaram outra ferramenta (uv, pip-tools, conda) e não ganham nada com a troca.

Conceitos-chave

pyproject.toml

Arquivo padrão do Python que descreve o projeto: nome, versão, dependências com faixas de versão e configurações de ferramentas.

poetry.lock

Registra a versão exata de cada pacote resolvido, inclusive as dependências indiretas. Deve ir para o Git.

Ambiente virtual

Pasta isolada com o interpretador e os pacotes do projeto. O Poetry cria e usa um ambiente por projeto.

Grupos de dependências

Separam dependências por uso, como dev ou test, instaladas ou não com --with e --without.

Build e publish

poetry build gera wheel e sdist em dist/; poetry publish envia para o PyPI ou para um repositório privado.

Armadilhas & Fixes

ErroCausaCorreção
pyproject.toml changed significantly since poetry.lock was last generatedAlguém editou as dependências no pyproject.toml sem atualizar o lock.Rode poetry lock e faça commit dos dois arquivos juntos.
SolverProblemError: version solving failedDuas dependências exigem faixas de versão incompatíveis de um mesmo pacote, ou a versão do Python do projeto não é suportada.Leia a cadeia de conflito na mensagem, relaxe a restrição com poetry add pacote@^X ou ajuste python no pyproject.toml.
ModuleNotFoundError no editor ou no terminalO editor ou o shell está usando outro interpretador, não o ambiente virtual do Poetry.Veja o caminho com poetry env info --path e selecione esse interpretador no editor, ou rode o comando com poetry run.
