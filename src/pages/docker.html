Docker

containers & registry

dockerbuildrun27 comandos

Resumo

Docker empacota uma aplicação com tudo que ela precisa (runtime, bibliotecas, configuração) numa imagem, que roda isolada como container em qualquer máquina com Docker.

  • Para que serve: garantir que a aplicação rode igual no notebook, no CI e em produção, e subir dependências (banco, cache) com um comando.
  • Quando usar: empacotar serviços para deploy em Kubernetes, Cloud Run ou similares; montar ambientes de desenvolvimento com Docker Compose; isolar ferramentas sem instalá-las no host.
  • Quando evitar: aplicações desktop com interface gráfica, cargas que precisam de acesso direto a hardware específico, ou quando um binário estático simples resolve.

Conceitos-chave

Imagem

Pacote somente leitura, em camadas, com o sistema de arquivos e a configuração da aplicação. É identificada por nome e tag (app:1.0).

Container

Instância em execução de uma imagem, com processo, rede e sistema de arquivos isolados. Pode ser criado, parado e removido sem afetar a imagem.

Dockerfile

Receita para construir a imagem: cada instrução (FROM, COPY, RUN) gera uma camada, reaproveitada em cache nos próximos builds.

Registry

Servidor que armazena e distribui imagens (Docker Hub, Artifact Registry, GHCR). push envia, pull baixa.

Volume

Armazenamento que sobrevive ao container. Volumes nomeados são gerenciados pelo Docker; bind mounts apontam para uma pasta do host.

Docker Compose

Arquivo YAML que descreve vários serviços (app, banco, cache) com redes e volumes, subidos juntos com docker compose up.

Como funciona

Comandos

🏗️ Build & Run

Build imagemdocker build -t minha-app:1.0 .
Run containerdocker run -d -p 8080:8080 --name app minha-app:1.0
Run com env varsdocker run -e DB_URL=postgres://... minha-app
Run interativo (debug)docker run -it --rm ubuntu bash
Entrar em container rodandodocker exec -it app bash
Logs do containerdocker logs -f app
Parar containerdocker stop app

📦 Registry & Images

Login no registrydocker login gcr.io
Push imagemdocker push gcr.io/PROJETO/minha-app:1.0
Pull imagemdocker pull nginx:alpine
Listar imagens locaisdocker images
Remover imagemdocker rmi minha-app:1.0
Tag para registrydocker tag minha-app:1.0 gcr.io/PROJETO/minha-app:1.0
Buscar imagensdocker search nginx

🧹 Limpeza & Volumes

Listar containersdocker ps -a
Remover container paradodocker rm app
Remover todos os paradosdocker container prune
Limpar imagens não usadasdocker image prune
Criar volumedocker volume create meu-volume
Mount volumedocker run -v meu-volume:/data minha-app
Bind mount (host)docker run -v /host/path:/container/path minha-app

Cuidado com o prune

docker container prune e docker image prune apagam recursos parados sem volta. Use docker ps -a e docker images antes para conferir o que será removido.

Armadilhas & Fixes

ErroCausaCorreção
Cannot connect to the Docker daemonO daemon do Docker não está rodando ou o socket /var/run/docker.sock não está acessível.Docker não está rodando. Inicie: sudo systemctl start docker ou no macOS: abra Docker Desktop.
Permission deniedSeu usuário não pertence ao grupo docker, que tem permissão no socket do daemon.Adicione seu usuário ao grupo docker: sudo usermod -aG docker $USER e faça logout/login.
Port already in useOutro processo ou container já escuta essa porta no host.Mude a porta do host: docker run -p 8081:8080 ... ou pare o processo usando a porta: sudo lsof -i :8080.
No space left on deviceImagens antigas, containers parados, volumes órfãos e cache de build acumulados ocupam o disco.Limpe containers/imagens: docker system prune -a. Verifique espaço: df -h.
exec user process caused "no such file or directory"O script de entrada tem quebras de linha do Windows (CRLF) ou o shebang aponta para um interpretador que não existe na imagem.Problema de line endings no Windows. Use dos2unix no Dockerfile ou clone com git config core.autocrlf false.

Cuidado com o system prune

docker system prune -a remove todas as imagens sem container em uso, além de containers parados e cache. Com --volumes, apaga também os dados dos volumes.
