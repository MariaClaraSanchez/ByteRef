Agentes & Tool Use

ferramentas, loop do agente e MCP

agentstool usemcp9 comandos

Resumo

Com tool use, você descreve funções da sua aplicação (nome, descrição e parâmetros em JSON Schema) e o modelo pede para chamá-las quando precisa. Um agente é esse processo em loop: o modelo escolhe a ferramenta, sua aplicação executa, o resultado volta e o ciclo repete até a resposta final.

  • Para que serve: consultar APIs e bancos, executar ações e combinar vários passos que o modelo planeja sozinho.
  • Quando usar: tarefas com vários passos difíceis de prever, como suporte que consulta pedidos ou triagem de incidentes, em que erros podem ser detectados e revertidos.
  • Quando evitar: quando uma única chamada ou um fluxo fixo controlado pelo seu código resolve; agentes custam mais, demoram mais e erram de formas menos previsíveis.

Conceitos-chave

Ferramenta (tool)

Função da sua aplicação exposta ao modelo com name, description e input_schema. A descrição diz ao modelo quando usá-la.

input_schema

JSON Schema dos parâmetros. Com strict: true e additionalProperties: false, a entrada gerada sempre segue o schema.

Loop do agente

Enquanto stop_reason for tool_use: executar as ferramentas pedidas, devolver os resultados e chamar o modelo de novo.

tool_result

Bloco que devolve a saída de uma ferramenta, ligado ao pedido pelo tool_use_id. Erros voltam com is_error: true.

MCP

Model Context Protocol: padrão aberto para expor ferramentas, dados e prompts a aplicações de IA por meio de servidores reutilizáveis.

Human-in-the-loop

Pedir confirmação de uma pessoa antes de ações com efeito real (apagar, pagar, enviar), em vez de deixar o agente decidir sozinho.

🔁 Loop do agente

Python · loop manual
import json
import anthropic

client = anthropic.Anthropic()

def executar(nome: str, entrada: dict) -> str:
    if nome == "consultar_pedido":
        return json.dumps(buscar_pedido(entrada["pedido_id"]))  # sua função
    raise ValueError(f"ferramenta desconhecida: {nome}")

messages = [{"role": "user", "content": "Cadê meu pedido PED-1234?"}]

for _ in range(10):  # limite de iterações
    response = client.messages.create(
        model="claude-opus-5-5", max_tokens=16000, tools=tools, messages=messages,
    )
    if response.stop_reason != "tool_use":
        break
    messages.append({"role": "assistant", "content": response.content})
    resultados = []
    for bloco in response.content:
        if bloco.type != "tool_use":
            continue
        try:
            saida = executar(bloco.name, bloco.input)
            resultados.append({"type": "tool_result", "tool_use_id": bloco.id, "content": saida})
        except Exception as erro:
            resultados.append({"type": "tool_result", "tool_use_id": bloco.id,
                               "content": str(erro), "is_error": True})
    messages.append({"role": "user", "content": resultados})  # todos numa só mensagem
else:
    raise RuntimeError("limite de iterações atingido")

print(next(b.text for b in response.content if b.type == "text"))
Python · tool runner (beta)
import json
import anthropic
from anthropic import beta_tool

client = anthropic.Anthropic()

@beta_tool
def consultar_pedido(pedido_id: str) -> str:
    """Busca status e itens de um pedido pelo ID.

    Args:
        pedido_id: ID do pedido, ex.: PED-1234.
    """
    return json.dumps(buscar_pedido(pedido_id))  # sua função

runner = client.beta.messages.tool_runner(
    model="claude-opus-5-5",
    max_tokens=16000,
    tools=[consultar_pedido],
    messages=[{"role": "user", "content": "Cadê meu pedido PED-1234?"}],
)
for message in runner:  # o SDK executa as ferramentas e repete até terminar
    print(message.stop_reason)
Python · confirmação humana antes de agir
def cancelar_pedido(pedido_id: str) -> str:
    resposta = input(f"O agente quer CANCELAR {pedido_id}. Confirmar? [s/N] ")
    if resposta.strip().lower() != "s":
        return "Cancelamento recusado pelo usuário. Não tente de novo sem nova instrução."
    cancelar(pedido_id)  # sua função com efeito real
    return f"Pedido {pedido_id} cancelado."

Armadilhas & Fixes

ErroCausaCorreção
Agente em loop, com custo disparandoNão há limite de iterações, e a ferramenta devolve erros vagos, então o modelo tenta de novo sem parar.Limite iterações e orçamento, devolva erros claros com is_error: true e registre cada chamada em log.
Prompt injection vindo de uma ferramentaConteúdo externo (e-mail, página web, ticket) devolvido pela ferramenta contém instruções que o modelo pode seguir.Trate resultados como dados, dê às ferramentas o mínimo de permissão e exija confirmação humana para ações sensíveis.
Ação destrutiva sem confirmaçãoA ferramenta executa direto o que o modelo pediu: apagar, pagar, enviar e-mail.Peça confirmação humana, ofereça modo de simulação (dry-run) e use credenciais com permissões mínimas.
400: tool_use sem tool_result correspondenteAlgum resultado ficou faltando, foi enviado em mensagens separadas ou com o tool_use_id errado.Devolva um tool_result para cada tool_use, todos numa única mensagem user logo após a resposta do assistente.
400 ao forçar uma ferramentatool_choice do tipo any ou tool não é aceito nos modelos Claude atuais. Referência: out/2026.Use tool_choice: auto com uma instrução clara no prompt e strict: true para garantir o formato.

Ferramentas com efeito real exigem confirmação humana

Qualquer ferramenta que apaga dados, movimenta dinheiro, envia mensagens ou altera produção deve pedir confirmação de uma pessoa antes de executar. O modelo pode interpretar mal o pedido ou ser manipulado por conteúdo externo.
